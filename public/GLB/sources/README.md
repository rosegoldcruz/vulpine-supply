# Isometric floor-plan sources

These source renders are intentionally distinct and are used as inputs for Meshy image-to-3D generation:

- `floor-plan-l-apartment.png`: L-shaped two-bedroom apartment.
- `floor-plan-family-rectangular.png`: wide rectangular three-bedroom family home.
- `floor-plan-courtyard-u.png`: U-shaped four-bedroom courtyard home.

Generated on 2026-10-03. Keep these files alongside their resulting GLBs for traceability and to avoid submitting duplicate layouts to Meshy.
